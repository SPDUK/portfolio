# Arcade implementation

The Arcade contains Asteroids, Snake, Breakout, Lights Out, Pixel Studio, Beat Lab, Gravity Sling, and Prism Relay. Opening `/arcade` shows the user-approved CRT launcher: a vertical selection menu, selected-game artwork, and an explicit Start game action. The catalog owns labels, descriptions, shareable query routes, and Terminal commands. The Arcade receives activity, motion, sound, route selection, and sound-preference updates from the desktop.

`ArcadeLauncher.tsx` provides semantic radio choices with roving keyboard focus, wrapping Up/Down, Home/End, Enter to launch, and thresholded mouse-wheel selection. Native taps select an activity without starting it. Browsing mounts no game and creates no audio. The selected activity and launcher/game view form a discriminated union in `Arcade.tsx`. Back to game select and Escape return from gameplay without retaining a live game; the selection is remembered. Escape from the launcher minimizes Arcade through the existing desktop action.

All explicit `/arcade?game=<id>` links open their game directly, including Snake. Missing, empty, or invalid game parameters open the launcher. The route builder always writes an explicit game parameter; Terminal `play snake` therefore continues to start Snake. Choosing a preview leaves the URL unchanged, and starting or returning updates the existing desktop route.

The generated bezel is a native-alpha PNG over semantic content. A named size container fits the launcher to its app window in both dimensions. A grid reserves heading, Start, and footer space, with the preview filling the remaining height; type and gaps use both width and height container units. Tall narrow panels stack menu and preview, while short narrow panels use a compact split. Only the game list scrolls. A ResizeObserver keeps the selected radio visible as its list changes size. Pixel artwork is generated for all eight choices, with a dedicated wide Asteroids image matching the approved comp. Exact image prompts and origin records are bundled in `static/arcade/SOURCES.json` and embedded in every PNG. Press Start 2P is self-hosted with its SIL Open Font License. CRT scanlines are static and limited to the launcher; playable activities retain their existing rendering and motion preferences.

## Verification

The added toys keep their rules and persistence validation in `lightsOutLogic.ts`, `pixelStudioLogic.ts`, and `beatLabLogic.ts`:

- Lights Out generates solvable boards by applying legal moves to an empty grid. Its row-chasing solver finds a shortest solution for hints after arbitrary moves.
- Pixel Studio interpolates pointer strokes, groups each drag into one undo, mirrors painting and erasing, and validates its saved draft. PNG export preserves transparent pixels. Drawing history is bounded to 50 entries.
- Beat Lab stores four eight-step instrument patterns and tempo. Web Audio schedules notes against the audio clock, skips stale time after stalls, and closes its context when the toy unmounts. Sound starts only after an explicit Play gesture, and mute, focus loss, hidden pages, and workspace changes stop playback.
- Gravity Sling separates its fixed-step gravitational simulation and canvas renderer from controls. Three authored courses have verified winning settings; segment collision prevents tunneling, and flight time, trails, and catch-up work are bounded. Dragging aims but never launches. Losing attention pauses until explicit resumption. With motion disabled, Launch calculates and displays the complete trajectory immediately.
- Prism Relay traces a beam through a finite grid, detecting repeated cell/direction states to stop loops. Three authored puzzles contain two, four, and six mirrors. Hints identify a mirror without rotating it. Native mirror buttons support arrow navigation and Space/Enter, with 44px touch targets at 320px. The brief beam reveal respects both motion preferences.

`PlayToys.browser.test.mjs` exercises solving/resetting, keyboard input, pointer strokes, undo, draft restoration, PNG pixels, actual audio output and cleanup, plus narrow touch layouts. `GravitySling.browser.test.mjs` verifies native aim controls, every course solution, attention pause, motion changes, and touch aiming. `PrismRelay.browser.test.mjs` verifies keyboard rotation, hints, all puzzle solutions, progression, and narrow touch targets. `Startup.browser.test.mjs` covers startup, replay, route/restoration behavior, focus, both motion preferences, no JavaScript, and delayed hydration.
